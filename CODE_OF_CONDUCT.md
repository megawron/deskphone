# Code of Conduct

Deskphone adopts and follows the [GNOME Code of Conduct](https://conduct.gnome.org/).

As a project targeting the GNOME ecosystem, we are committed to providing a welcoming,
respectful, and harassment-free experience for everyone — regardless of experience level,
identity, background, or personal characteristics.

## Expected Behavior

- Be friendly, patient, and welcoming.
- Be considerate and respectful in discussions, issues, and pull requests.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the community and users.

## Reporting Issues

If you experience or witness unacceptable behavior in this repository or related project spaces,
please report it by opening a confidential note or contacting the maintainer via
[GitHub (@megawron)](https://github.com/megawron) or the GNOME Code of Conduct Committee
(for GNOME infrastructure spaces) as described at <https://conduct.gnome.org/>.
